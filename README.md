# Amigurumemi — Crochet and knitting project management system

**Факултетен номер:** 2401321001  
**Име:** Мариела Антонова

## Описание

Amigurumemi е уеб приложение за управление на проекти за плетене, схеми и прежди. Потребителите могат да създават и управляват проекти, да разглеждат и организират схеми по категории и ниво на трудност, както и да следят използваните материали и разходите за всеки проект. Системата предоставя управление на потребители, автентикация чрез JWT и възможност за проследяване на прогреса на проектите.
